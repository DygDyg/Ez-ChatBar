# Ez ChatBar

![Ez ChatBar](https://media.forgecdn.net/attachments/description/403805/description_65f3bcee-2adf-40cd-9f45-5f392c7aa2d1.png)

Quick chat channel buttons for the default World of Warcraft chat.

## English

**Ez ChatBar** adds a compact movable bar with colored bubbles for fast access to Say, Yell, Party, Raid, Guild, Officer, Instance and custom commands.

### Templates

| Token | What it does |
| --- | --- |
| `#text#` | Inserts text already typed in the chat input |
| `#key#` | Inserts your Mythic+ keystone link from bags |

Example: `/GUILD #text##key#`

### How to use

- **LMB** on the anchor — drag the bar
- **RMB** on the anchor, `/ezcb`, or **Esc → Options → AddOns → EZChatBar** — settings
- **LMB** on a bubble — open chat with that command

## Русский

**Ez ChatBar** добавляет компактную перетаскиваемую панель с цветными пузырьками для быстрого доступа к Say, Yell, группе, рейду, гильдии, офицерскому и инстанс-чату, а также к своим командам.

### Шаблоны

| Токен | Что делает |
| --- | --- |
| `#text#` | Подставляет текст, уже набранный в поле ввода чата |
| `#key#` | Вставляет ссылку на ваш ключ Mythic+ из сумок |

Пример: `/GUILD #text##key#`

### Как пользоваться

- **ЛКМ** по якорю — перетащить панель
- **ПКМ** по якорю, `/ezcb` или **Esc → Настройки → Аддоны → EZChatBar** — настройки
- **ЛКМ** по пузырьку — открыть чат с нужной командой
