# EzChatBar

Кнопки быстрого доступа к каналам стандартного чата (Midnight 12.1+).

## Использование

- Перетаскивание якоря ЛКМ
- ПКМ по якорю или `/ezcb` / `/ezchatbar` — настройки
- ЛКМ по пузырьку — открывает чат с командой

## Шаблоны команд

| Шаблон | Описание |
|--------|----------|
| `#text#` | Текст, уже набранный в поле ввода чата |
| `#key#` | Ссылка на ваш ключ Mythic+ из сумок |

Пример: `/GUILD #text##key#`

## Совместимость

- Version: `0.60.0`
- Interface: `120100` (WoW 12.1.0)
- Сохранённые настройки (`EZ_ChatBar_Bubble`, `WindowPosition`) переносятся со старых версий
